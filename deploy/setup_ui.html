☁️ 第 1 步：选择认证钥匙（二选一）

两种都能让 Agent 推送笔记。推荐新手选 Token；会用命令行的选 SSH。
🔑GitHub Token可推送 ✓
最简单：网页上点几下生成一串字符，粘贴进来即可。推荐所有人使用。
🗝️SSH Keys可推送 ✓
密钥对方式：本机生成公私钥，公钥贴 GitHub、私钥贴这里。适合会用命令行的人。
① 打开申请链接：github.com/settings/personal-access-tokens/new（经典版：github.com/settings/tokens/new，勾选 repo 整个分类）
② Token name：随便起名，如 cht-obsidian
③ Repository access：选 Only select repositories → 只勾选你的笔记仓库（最小权限更安全）
④ Permissions → Contents 设为 Read and write（其余保持 No access）
⑤ Expiration：建议 90 天或 No expiration
⑥ 点 Generate token → 立刻复制生成的 github_pat_… 长串（只显示这一次！）
令牌只保存在本服务器的 0600 权限文件里，不会回显到状态页、不会进日志。
终端（Windows 用 PowerShell）执行：ssh-keygen -t ed25519 -C "cht-obsidian"，一路回车。生成两个文件：私钥 ~/.ssh/id_ed25519、公钥 ~/.ssh/id_ed25519.pub。
打开 github.com/settings/keys → New SSH key → Key type 选 Authentication Key → 粘贴 .pub 公钥内容（一整行，ssh-ed25519 开头）→ Add SSH key。
粘贴 ~/.ssh/id_ed25519 私钥全文（-----BEGIN OPENSSH PRIVATE KEY----- 开头），不是 .pub 公钥！私钥将写入服务器 /data/gitkey（权限 600）。
格式：你的用户名/仓库名，例如 cuohuatang/cut-obsidian-brain。仓库需在 GitHub 上先创建好（建议 Private 私有，里面是你全部笔记）。创建入口：github.com/new（不要勾选任何初始化文件）。
笔记推送到仓库的哪个分支，默认 main 即可。

🔄 第 2 大步：手动同步（平时 Agent 会自动推）

保存配置后，Agent 调用 cm_github_push / cm_brain_finalize 时自动增量推送。电脑端 Obsidian 装 obsidian-git 插件指向同一仓库，即可开机自动拉取，实现多端同步。

② Agent 连接地址：http://154.12.41.33:8899/sse + 本页第 0 步的令牌，直接填进你的 MCP 客户端。
③ 传输协议：当前为 SSE。改协议需修改 /opt/cht-obsidian/.env 后重启容器，属运维操作。
